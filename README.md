# 潮汐學院 · 潮汐小島

> 把每一題，都變成照亮海面的光。

離線、免帳號的學測備戰遊戲，目前版本 **8.9.0**。建置後打開 `dist/isle.html`，雙擊就能玩，不需要伺服器或網路（字型除外，離線時改用系統字型）。所有學習模式都在島上；舊的 `index.html`（學習中心）會自動轉到小島。

**線上版**：<https://ragorothers-alt.github.io/tidal-academy/>——推上 `main` 時，GitHub Actions 會跑測試、執行 `python build.py`，把 `dist/` 發布到 GitHub Pages（`.github/workflows/pages.yml`）。進度存在各自瀏覽器的 localStorage；線上版沒有 laya 轉送，島民改用本機的作息決定要做什麼。

## 潮汐小島：動物森友會式的學測生活

一座跟現實時間同步的日系奇幻小島「星環學院」，住著十位學院導師。導師們以人形角色陪你備考，各有自己的科目、興趣與步調。從碼頭穿過星環城門、走過主街與噴泉廣場，北邊白石台地上是博物館、考場、圖書館與觀星台，天上浮著白色城堡與魔法星環；西邊是有松林、瀑布與山頂祠堂的高地。和他們聊天、釣魚、捉蟲、挖化石、布置房間——採集與導師練習會用到學測題，題庫與單字各自共用間隔複習紀錄；概念練習另記進度。

玩家與學院導師、店長阿潮、圖書館館員書棲、飯店經理阿浪都採用人形 3D 模型，帶一點年輕的魔法學院風。尚未列入人形角色陣容的旅客仍保留 Q 版動物造型。

阿潮負責商店與收購，親切招呼每位來訪者；書棲負責圖書館與複習，安靜地替讀者留頁；阿浪負責潮汐渡假飯店，熱心邀請你一起布置客房。

剛上島先跟左上角的四步引導：認識導師、答對一題、採集一次、捐出第一件展品。貝殼是手作材料，不能當展品；化石先找史遙鑑定，再選捐贈。之後每天先開手機「今日學習」，想自己挑題再到「自由練習」。

| 島上的事 | 怎麼和讀書連在一起 |
|---|---|
| **十位島民** | 每科一位導師（名字與個性見上表）。「一起練習」一組 5 題、不限時，難度跟著這科表現調整，答錯看完解析繼續；想拚紀錄另選「連續挑戰」。答對得鈴錢與好感度，也能聽讀書秘訣、閒聊。第一次一起練習、完成委託、主人在家時拜訪（史遙在博物館）、送禮都會記下；超過兩天再見面時，導師偶爾會提起，並寫進回憶錄 |
| **釣魚** | 浮標下沉時按下去，10 秒內答對英文單字才拉得上來。65 種台灣魚類，出沒依月份與時段（含青鱂魚、烏魚季、黑鮪等季節魚）；夜間海釣也有白腹鯖與日本銀帶鯡（丁香魚），不只高稀有度的魚 |
| **捉蟲** | 慢慢走近揮網，20 秒內答對國文題。57 種小生物（遊戲歸在「蟲」類，含蟹、蛙，以及夏季鍬形蟲、春夏螢火蟲、冬季紫斑蝶）；奔跑會把牠嚇跑 |
| **化石與博物館** | 每天 4 個星形裂縫，挖到化石交給史遙鑑定：答對對應科目的題目才知道是什麼。25 種化石，捐給博物館會聽到對應的地科、生物、歷史知識 |
| **委託** | 每天約 3 件島民委託：釣指定的魚、抓指定的蟲、帶化石、3 題連答特訓、送包裹給其他島民。有合適單元時，其中一件是**弱點委託**：學習引擎優先挑未練過或較弱的單元，由該科導師邀你一起練 4 題（答對 3 題過關並送上單元重點）；還沒練過的單元會改說「一起認識」，不當成已確認的弱點 |
| **信箱** | 每天收到兩封導師來信，有錯題時其中一封由錯題最多的那科寄來，附單元的潮汐筆記；沒有錯題時輪流寄信，好感度高時可能附禮物。最多保留 30 封，可收藏 5 封；信箱滿時保留收藏信，優先移除最舊的已讀信，若須移除未讀信會先領出禮物 |
| **房間與家具** | 在自己家與飯店客房按 `F`、點裝潢鈕或開手機「裝潢」App；自己家的第一人稱可用滾輪拉到最近再往前滾；手機到設定切換「第一人稱視角」。每個房間最多擺 160 件，同一格不能重疊鋪地毯。共 180 件可收藏家具（含每科 2 件好感禮物、30 件研究家具、40 件飯店家具與 18 件夢幻家具）；壁紙與地板各 18 款，一般各 10 款用鈴錢購買，飯店各 8 款用優惠券兌換。阿潮的店每天換貨；島民好感度到一定程度會送家具 |
| **釣魚大賽與捕蟲大會** | 每週三（Lexi 主持）與週五（森主持）的限時 3 分鐘比賽：釣魚要答英文單字、捉蟲要答國文題，魚越大、蟲越稀有分數越高；金／銀獎可得獎盃家具，銅獎與參加獎送鈴錢 |
| **季節與倒數活動** | 週末模擬考祭典（國英數社自 10 題，依成績得金／銀／銅獎盃）、學測倒數 100／30／7 天、跨年煙火、學測前夜、考後慶典、春櫻、中秋 |
| **拜訪島民的家** | 九位導師每天有在家時段，可以進門拜訪、在房間裡聊天；深夜有人會睡著。九間導師住宅各有主題（例如雷恩家有特斯拉線圈燈和牛頓擺），加上玩家自己的家；史遙在博物館，沒有獨立住家入口。主人不在家也能進去逛，桌上留有各自的紙條；整棟室內的書桌先聊故事再練 3 題，指定展示點依提示翻筆記或圖鑑 |

**操作：** `WASD` 移動、`Shift` 奔跑、空白鍵跳躍（`J` 也可以跳；落地前最多三連跳，第三跳前空翻；跳得夠高就能越過河流、物件，甚至跳上高台）、`E` 互動（`Enter` 也可以）、`1/2/3/4` 釣竿／捕蟲網／鏟子／澆水壺、`F` 第一人稱視角（島上）、`Tab` 手機、`I` 口袋、`F` 裝潢（自己家與飯店客房）、`G` 島嶼設計、`P` 拍照；也可以點地面移動、點島民聊天。滾輪調整遠近，自己家用拉近的方式進入第一人稱。

**面板與鍵盤：** `Tab`／`Shift+Tab` 在目前面板的按鈕、輸入框之間循環，`Esc` 關閉面板；剛開手機主畫面時，再按 `Tab` 收起，方向鍵可在 App 間移動。用鍵盤開啟後關閉，焦點會回到原按鈕。寫日記、改名字、搜尋單字時，字母鍵交給輸入框；長面板捲動時標題與關閉鈕留在上方。

**手機與平板：** 左半邊按住拖曳出現搖桿，輕推慢走、推遠奔跑；右半邊拖曳轉視角，兩指縮放，跳躍與互動用畫面按鈕，裝潢時有旋轉、結束等擺放按鈕。直向時工具列在左側較高處，左下角留給搖桿；矮螢幕橫向時改放下方中央。小地圖縮放與任務欄收合有較大的觸控範圍，進入住家、圖書館、博物館時收起小地圖。長選單可在選項區內捲動；小螢幕在對話裡作答（選擇題、選填題）與季節橫幅顯示時通知先排隊，船員登記完成前也暫緩通知。

**畫面：** 動森式低角度鏡頭與滾筒地平線、程式生成的積雲與天空、手繪感草地與岩層材質、隨風擺動的草叢、葉片紋理、水光、環境光遮蔽與景深、遮擋鏤空、低多邊形卡通風、現實時間日夜（夜晚窗戶與路燈亮起、星空）、柔和陰影、黃昏的金色逆光（泛光、光束、太陽光暈、逆光輪廓、浮塵與螢火蟲，可在設定關閉）、帶魔法學院風的人形 3D 角色、仍採 Q 版造型的旅客，以及涵蓋 189 種圖鑑條目的像素圖示。系統開啟「減少動態效果」時，進出建築用短淡入、拍照不白閃、物品不飛入口袋，循環動畫只播一次。

## 學習模式（都在島上）

| 模式 | 在哪裡 | 說明 |
|---|---|---|
| **今日路線** | 手機「今日學習」 | 每天選 20／40／60 分鐘：學習 10／20／35 分鐘（題數、非選題折算、單字卡、專注、練習遊戲都算）加島上的事 1–3 件；20 分鐘路線就是連續學習的門檻。加碼可選每日潮汐 12 題（到期複習＋弱點＋新題）、單字或專注。 |
| **今天的複習** | 手機「今日學習」「自由練習」、圖書館、床、潮靈、導師 | 錯題與到期題合成一份清單（只排要考的考科，每天約 20 題、考前一週 12 題，剛答過的 20 分鐘內先不排）。各場景用自己的方式出同一份清單裡的題目，完成量共用：在哪裡複習都算；今天的份做完了，剩下的可以明天再來。 |
| **考科航線／自由練習** | 手機學習區 | 考科航線：要考的考科、各考科的級分估算與最弱單元（直接補弱點、開航海圖），以及讀書計畫、成績統計、學習週報。自由練習：今天的複習、每日潮汐、單字燈塔、錯題本、夢境複習、非選練習、激流衝刺、專注時光與所有練習遊戲。 |
| **備考航線** | 我的檔案、船員登記 | 選要考的考科與主力考科（最多 2 科）：每日潮汐、讀書計畫、考前衝刺與弱點委託只排要考的考科，主力考科新題多一倍；其他科目照樣能自由探索。 |
| **一起練習** | 各科導師 | 一組 5 題、不限時，難度依這科表現升降；答錯看解析繼續。最後兩題偶爾改成易混題對照（共 40 組）：先想兩題該用什麼方法，答完再看差別；只從該科可用、未冷卻的組合抽，同一組 7 天內不重複。「連續挑戰」另外拚連對紀錄，每題獎金最多 1.6 倍。 |
| **把握與錯因** | 導師一起練習、圖書館複習、住家書桌等對話練習 | 不限時且至少 3 題的練習會抽 2 個題位，若該題是科目單選題，選答案後再標「有把握」（`E`）或「有點猜」（`G`），觸控直接點按鈕；確認前可換答案。猜對不升格（首次見到的題目先到第 1 格），保留近期複習；很有把握卻答錯會提醒看解析，錯題本也會標示。一組最多在首道錯題的解析後問一次錯因：觀念不清楚、計算或粗心、漏看條件、用猜的，可跳過；兩種提示都能在設定關閉。 |
| **概念應用** | 練習護照、成績統計 | 拋射、選制、期望值、函數圖形、月相、週期表、年代、英文聽力、成語、孟德爾遺傳十個概念：每輪都是新的數字與情境，一輪答對八成以上、而且隔幾天到期時再做對才升一格，兩格以上算「已驗證」。和題庫題目的熟練分開算，但每一題都算進今天的學習。 |
| **觀察筆記／標本研究** | 手機「圖鑑」、史遙 | 釣魚、捉蟲、潮池、神秘島答錯時生物溜走但記進筆記，之後答對一題新的同類題就補完研究、帶回一隻；季節、時段或天氣不對看不到的魚蟲，可以找史遙做標本研究（3 題對 2 題）。 |

小島的原始碼是 ES 模組；`build.py` 會把它轉成一般腳本、把 `vendor/three/three.cjs` 包成全域 `THREE`，所以打包版用 `file://` 直接開也能跑。資產檔名帶內容雜湊，清單在 `dist/assets/manifest.json`。

渲染效能：頂點著色器把遠處往下彎（`engine.js` 的 `uCurve`），所以視錐剔除也照同樣的彎曲判斷（`bentHit`）；新加的物件用 `cullable(o)` 設 `frustumCulled`，一般不要直接關掉剔除。靜態的群組用 `props.js` 的 `mergeStatic` 合併（會順便做陰影替身）；之後要換材質或移動的零件放在 `userData.prop` 子群組或設 `userData.noCull`。

進入整棟室內時，先以黑幕遮住建模與著色器預先編譯；離開時清理此次建立的光效、展品圖卡與家具專屬幾何，夢境島也追蹤並釋放自有幾何與材質，共用資源保留。家具縮圖每批最多補兩張、面板關閉即停止，釣線重用頂點緩衝；窗景材質複製時共用 uniforms。laya 連線失敗會逐步延長重試，連續 5 次失敗後停止自動嘗試，打開設定可立即重試；沒有代理服務的環境直接停止自動重試。

## 限制

- 題目依 108 課綱學測範圍原創撰寫，**不是大考中心官方試題**，也沒有經過外部難度校準。
- 單字分級依大考中心參考詞彙表的常見分級整理，個別字的級數可能有出入。
- 進度只存在單一瀏覽器，沒有雲端同步，換裝置請用手機「設定」的匯出／匯入。匯入會檢查存檔標記與基本結構，並整理小島的巢狀欄位；相簿與回憶錄的照片不含在 JSON 備份內。
- 舊版：學習中心頁面的最後版本在 git 標籤 `v6.74.1`（v6.75.0 移除）；方塊群島是 v2.0.0 的試做版（標籤 `v2.0.0`），最初的 v0.12 封存在 `legacy/v0.12/`。
