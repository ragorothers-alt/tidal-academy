## 潮汐小島：動物森友會式的學測生活

一座跟現實時間同步的日系奇幻小島「星環學院」，住著十位學院導師。從碼頭穿過星環城門、走過主街與噴泉廣場，北邊白石台地上是博物館、考場、圖書館與觀星台，天上浮著白色城堡與魔法星環；西邊是有松林、瀑布與山頂祠堂的高地。和他們聊天、釣魚、捉蟲、挖化石、布置房間——**每一件事都在複習學測**，所有玩法共用同一套間隔複習。

| 島上的事 | 怎麼和讀書連在一起 |
|---|---|

| **捉蟲** | 慢慢走近揮網，20 秒內答對國文題。50 種蟲（含夏季鍬形蟲、春夏螢火蟲、冬季紫斑蝶）；奔跑會把牠嚇跑 |
| **化石與博物館** | 每天 4 個星形裂縫，挖到化石交給史遙鑑定：答對對應科目的題目才知道是什麼。25 種化石，捐給博物館會聽到對應的地科、生物、歷史知識 |

| **釣魚大賽與捕蟲大會** | 每週三（Lexi 主持）與週五（森主持）的限時 3 分鐘比賽：釣魚要答英文單字、捉蟲要答國文題，魚越大、蟲越稀有分數越高；金／銀獎可得獎盃家具，銅獎與參加獎送鈴錢 |

| **拜訪島民的家** | 每位島民每天有一段在家的時間，可以進門拜訪、在他的房間裡聊天；深夜有人會睡著。十間房各有主題（例如雷恩家有特斯拉線圈燈和牛頓擺） |
| **島民的日常與好感度** | 島民會在路上相遇聊天；好感度到 4／8／12／16／20 時觸發五段心事事件，送家具與鈴錢，第 3 段之後可以開「讀書會」（5 題、鈴錢加倍） |
| **導師研究計畫** | 好感度 4 以上和導師聊天選「研究計畫」：每位導師一個三階段的長期研究（例如雷恩的潮流點燈實驗、晶晶的海水分離筆記、岳的震央定位）。每個階段要好感度（8／14／20）、這一科的學習成果（累計答對 30 題 → 3 個單元試煉 2 星以上 → 熟練 40 題）與研究經費；完成後一起做研究（劇情裡帶出課本上的知識點），得到研究家具（共 30 件）。手機「研究計畫」看進度 |

## 限制

- 題目依 108 課綱學測範圍原創撰寫，**不是大考中心官方試題**，也沒有經過外部難度校準。
- 單字分級依大考中心參考詞彙表的常見分級整理，個別字的級數可能有出入。
- 進度只存在單一瀏覽器，沒有雲端同步，換裝置請用手機「設定」的匯出／匯入。
- 舊版：學習中心頁面的最後版本在 git 標籤 `v6.74.1`（v6.75.0 移除）；方塊群島是 v2.0.0 的試做版（標籤 `v2.0.0`），最初的 v0.12 封存在 `legacy/v0.12/`。
