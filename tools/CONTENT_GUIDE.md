# 潮汐學院題庫撰寫規範

潮汐學院是給台灣高中生準備**學測（2027/1/22–24，108 課綱）**的離線學習遊戲。題庫是遊戲的心臟：玩家打首領戰、衝刺模式和模擬考都要用它作答，答錯時會立刻顯示解析並排入間隔複習。所以**正確性第一，教學價值第二，數量第三**。

## 檔案格式

每個資料檔是普通 JS（不是 module），呼叫全域註冊 API：

```js
/* 數學（一）· 潮汐學院原創練習題，非大考中心官方試題 */
TA.addUnits('math', [
  {
    id: 'math-poly',              // 小寫英數與連字號，全域唯一
    name: '多項式函數',             // 單元名，簡短
    notes: [                       // 3–6 則「潮汐筆記」：考前最該記住的觀念、公式、易混淆點
      { t: '餘式定理', b: 'f(x) 除以 (x − a) 的餘式為 f(a)。<br>常見陷阱：除以 (2x − 1) 時代 x = 1/2。' },
      { t: '...', b: '...' }
    ],
    passages: {                    // 選填：閱讀題/克漏字共用的文章
      p1: 'In 1990, ...'
    },
    questions: [
      { id: 'math-poly-01', d: 2, q: '題幹', o: ['選項', '選項', '選項', '選項'], a: 1, e: '解析' },
      { id: 'math-poly-02', d: 3, type: 'multi', q: '題幹（多選）', o: ['五個', '選項', '...', '...', '...'], a: [0, 2], e: '逐項說明' },
      { id: 'en-read-03', d: 2, pid: 'p1', q: '依據文章…', o: [...], a: 3, e: '...' }
    ]
  }
]);
```

為**既有單元**追加題目（不必改動原檔；檔名任意，載入順序無關）：

```js
TA.addQuestions('ma1-poly', [
  { id: 'ma1-poly-x01', d: 2, q: '...', o: [...], a: 0, e: '...' },
  // 若需要新的閱讀材料，可在任一題附上 passages: { p9: '...' }，會合併進該單元
  { id: 'en-read-x01', d: 2, pid: 'p9', passages: { p9: 'Article...' }, q: '...', o: [...], a: 1, e: '...' }
]);
```

為既有單元追加潮汐筆記：

```js
TA.addNotes('ma1-poly', [
  { t: '三次函數的對稱中心', b: 'y = ax³ + bx² + cx + d 的圖形對稱於點 (−b/3a, f(−b/3a))。<br>常見陷阱：…' }
]);
```

單字檔：

```js
TA.addVocab([
  { w: 'abandon', pos: 'v.', zh: '拋棄；放棄', lv: 4, ex: 'The crew had to abandon the sinking ship.', exZh: '船員們不得不棄船。' }
]);
```

## 欄位規則

- `d`：難度 1（基本）/ 2（標準）/ 3（進階、鑑別度高）。目標比例約 30% / 45% / 25%。
- 單選題：`o` 為 4 個選項（3–5 也允許），`a` 為正確選項索引（0 起算）。**正確答案位置要平均分散在 A–D**，不要老是 B。
- 多選題：`type: 'multi'`，`o` 必須剛好 5 個，`a` 為索引陣列（可 1–5 個正確）。題幹結尾加「（多選）」。
- `e`：解析必寫。說明為什麼對，並點出主要干擾選項錯在哪。2–4 句，像好老師講的話，不要只寫「故選 B」。
- 文字標記只允許 `<u>`、`<b>`、`<i>`、`<sup>`、`<sub>`、`<br>`。數學用 Unicode：`x²`、`√3`、`π`、`θ`、`≤`、`≠`、`∞`、`→`、`·`、`×`、`÷`、`log₂ 8`、`aₙ`；複雜上下標用 `<sup>`/`<sub>`，例如 `2<sup>x+1</sup>`、`a<sub>n+1</sub>`。分數寫 `3/4` 或 `(x+1)/(x−2)`。化學式 `H<sub>2</sub>SO<sub>4</sub>`、離子 `Fe<sup>3+</sup>`。
- 空格用全形 `＿＿＿`。國文字音字形題要標示的字用 `<u>字</u>`。
- 不要使用 `<` 或 `>` 當不等號，請用 `＜ ＞ ≤ ≥`（避免被當成 HTML）。
- 題目必須能**只靠文字**作答，不能依賴圖片。需要圖表時，用文字描述資料（例如「某地 1 月均溫 16°C，7 月 29°C，年雨量 2400 mm 集中於夏季…」）。

## 內容原則

- 範圍：108 課綱學測範圍（國文、英文、數學A為主兼顧數B、社會＝歷史地理公民的部定必修、自然＝物化生地科的部定必修）。
- **原創**：題目、文章、例句都要自己寫。古典文學原文（公有領域）可引用；現代作家作品、補習班講義、大考中心官方試題不要照抄。
- 題型貼近學測：情境化、素養導向、資料判讀、跨概念。但也要有直接檢驗觀念的基本題，讓初學者能學會。
- 單元筆記要是真正有用的考前重點：公式、定義、口訣、時間軸、易混淆比較。每則 1–4 句。
- 每題寫完都要自己重新驗算一遍。數學與自然的計算題，請用 node 寫一次性腳本實際算出答案確認。歷史年代、人名、法條名稱不確定的就不要出。

## 驗證

寫完後執行：

```bash
node tools/validate-data.cjs src/data/你的檔案.js
```

必須顯示「✔ 驗證通過」。
